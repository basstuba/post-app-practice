# モバイルオーダーアプリ API設計書

## エンドポイント一覧
| ID | メソッド | エンドポイント | 何をするか | 認証 |
|:---|:--------|:--------------|:----------|:-----|
|API-01|GET|/api/menus/|メニューの一覧を取得する|不要|
|API-02|POST|/api/orders|注文を登録する|不要|
|API-03|GET|/api/orders/{注文番号}|注文を1件取得する|不要|
|API-04|DELETE|/api/orders/{注文番号}|注文を1件削除する|不要|
|API-05|GET|/api/orders|注文一覧を取得する|必要|
|API-06|PUT|/api/orders/{注文番号}|注文を受け渡し済に更新する|必要|

## 各エンドポイントの詳細

#### API-02: 注文を登録する

- **メソッドとエンドポイント**: POST /api/orders/user
- **認証**: 不要
- **送るもの**: 本文で商品名と商品価格と個数（必須・0~10の整数）
- **返すもの（うまくいったとき）**: 201。登録した注文（注文番号・合計金額・支払い手続きに進む行き先）
- **返すもの（うまくいかなかったとき）**: 422（送ったものに不備があるとき）

#### API-06: 注文を受け渡し済に更新する

- **メソッドとエンドポイント**: PUT /api/orders/{注文番号}
- **認証**: 必要
- **送るもの**: URLで注文の番号
- **返すもの（うまくいったとき）**: 200。受け渡し済にした注文（注文番号・商品名・商品価格・個数・受け渡し済であること）
- **返すもの（うまくいかなかったとき）**: 401（ログインしていないとき）/404（注文が見つからないとき）

## エラーレスポンス一覧
| 起きること | ステータスコード | 返すもの |
|:----------|:----------------|:--------|
|ログインしていない|401|ログインが必要である旨の文言|
|注文が見つからない（取得・更新・削除）|404|見つからない旨の文言|
|送ったものに不備がある（登録）|422|不備のあった項目と、その理由の文言|
