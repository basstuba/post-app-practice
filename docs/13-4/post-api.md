# 投稿アプリ API設計書

## エンドポイント一覧
| ID | メソッド | エンドポイント | 何をするか | 認証 |
|:---|:--------|:--------------|:----------|:-----|

|API-02|GET|/api/posts/{id}|投稿1件を取得する|必要|

## 各エンドポイントの詳細

#### API-03: 投稿1件を更新する

- **メソッドとエンドポイント**: PUT /api/posts/{id}
- **認証**: 必要
- **送るもの**: URLで投稿の番号と、本文で投稿のタイトル（必須・255文字以内）と投稿の本文（必須）と、カテゴリの番号（必須・登録済みのカテゴリのもの）
- **返すもの（うまくいったとき）**: 200。書き換えたあとの投稿1件（投稿の番号・タイトル・本文・カテゴリの番号・投稿者の番号・登録日時・更新日時）
- **返すもの（うまくいかなかったとき）**: 401（ログインしていないとき）/403（権限がないとき）/404（投稿が見つからないとき）/422（送ったものに不備があるとき）

## エラーレスポンス一覧
| 起きること | ステータスコード | 返すもの |
|:----------|:----------------|:--------|
|ログインしていない|401|ログインが必要である旨の文言|
|自分の投稿ではない（取得・更新・削除）|403|権限がない旨の文言|
|投稿が見つからない（取得・更新・削除）|404|見つからない旨の文言|
|送ったものに不備がある（更新）|422|不備のあった項目と、その理由の文言|
