# モバイルオーダーアプリ 例外一覧

| 起きること | どこで気づくか | そのときの処置 | 利用者への知らせ |
|:-----------|:---------------|:---------------|:-----------------|
| 選択した商品が、すでに売り切れている | 商品の値段と売り切れを読むとき | やめて元に戻す | 商品が売り切れたことと、選びなおしていただきたいこと |
| 注文を書き込む途中で失敗した | 注文を書き込むとき | やめて元に戻す | 注文を受け付けられなかったこと、もう一度試していただきたいこと |
| 支払いが済んだ知らせがいつまでも届かない | 支払いの結果を待つとき | 待って、3回まで決済サービスへ支払い結果を確認する。それでも確かめられなければ取り消し済にする | 支払いが確かめられなかったこと、お心当たりがある場合はお問い合わせいただきたいこと |
| お客様が入力した注文番号の注文が見つからない | 注文の状況を確認するとき | やめて元に戻す | 見つからないことと、注文番号を確認していただきたいこと |
| 受け渡し済にしようとした注文が、すでに取り消されている | 受け渡し済にするとき | やめて元に戻す | その注文が取り消されていること |
| 受け取り前でなくなった注文を、取り消そうとした | 取り消すとき | やめて元に戻す | すでに取り消せない状態であること |
