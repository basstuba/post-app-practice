# モバイルオーダーアプリ 入力チェック表

| 画面 | 項目 | 必須 | 文字数・桁数 | 形式・値の範囲 | 他の項目との関係 |
|:-----|:----|:-----|:------------|:-------------|:----------------|
|メニュー一覧画面|個数|任意|2桁以内|0~10の整数|-|
|注文一覧画面|注文番号|任意|6桁以内|半角数字のみ|-|

個人で注文する個数はほぼ1~2の想定ですが、最大10まで幅を持たせました。
注文番号は仕様書からは日々の注文数がどのくらいかわからない為、口頭で伝えやすい長さにしました。
どちらも仕様書には記載されていないので確認事項リストにも記載します。
