# 投稿アプリ画面一覧

| ID | 画面名 | 役割 | 主な利用者 |
|:---|:-------|:----|:-----------|
|SC-01|タイトル画面|未ログインの場合はログインとユーザー登録への入口を見せ、ログイン後は投稿一覧画面への入口を見せる（最初に開く画面）|ユーザー|
|SC-02|ログイン画面|メールアドレスとパスワードを入力してログインする|ユーザー|
|SC-03|ユーザー登録画面|ユーザーの名前とメールアドレスとパスワードを登録する|ユーザー|
|SC-04|投稿一覧画面|投稿を一覧で見せ、ユーザー自身の投稿には編集と削除への入口を見せる|ユーザー|
|SC-05|投稿編集画面|投稿内容のタイトルとトピックと本文を変更する|ユーザー|
