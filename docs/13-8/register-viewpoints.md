# 投稿アプリ テスト観点表

| ID | 何を確かめるか | 区分 | 元になった設計書 |
|:---|:--------------|:----|:----------------|
|TC-01|ログインしていなくても、タイトル画面が開ける|正常系|画面一覧のSC-01の行|
|TC-02|名前・メールアドレス・パスワードをすべて入れて登録すると、ユーザーが1件増える|正常系|CreateNewUser.phpの入力の決め事|
|TC-03|名前を空のまま登録しようとすると、登録されない|異常系|CreateNewUser.phpのnameの必須|
|TC-04|名前が255文字なら、登録される|境界値|CreateNewUser.phpのnameの上限|
|TC-05|名前が256文字だと登録されない|境界値|CreateNewUser.phpのnameの上限|
|TC-06|すでに登録されているメールアドレスで登録しようとすると、登録されない|異常系|CreateNewUser.phpのRule::unique|
|TC-07|メールアドレスの形になっていない文字列を入れると、登録されない|異常系|CreateNewUser.phpのemailの形式|
|TC-08|パスワードと確認用の欄が食い違うと、登録されない|異常系|CreateNewUser.phpのpasswordの一致確認|

名前とメールアドレスを何文字まで受け付けるのかは、このアプリでは決まっていない。コードの `max:255` は、`users` テーブルの列に入りきる限界と同じ数字で、受け付ける範囲を決めた設計書はどこにも無い。
