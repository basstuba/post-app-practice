#### UC-07: 商品の受け渡しを登録する

- **アクター**: 店員
- **事前条件**: 注文が1件以上ある
- **基本フロー**:
  1. 店員が注文の一覧画面にて該当する注文を開く
  2. システムが該当する注文の商品と個数を表示する
  3. 店員が受け渡しボタンを押す
  4. システムが注文のステータスを受け渡し済に変更する
  5. システムが該当注文を受け渡し前注文の一覧画面から非表示にする
- **代替フロー**:
  - 1a. 該当する注文が無い場合：システムは該当する注文が無い旨を表示する
- **事後条件**: 注文のステータスが受け渡し済となり受け渡し前注文の一覧画面から非表示になる
- **受け入れ条件**:
  - [ ] 注文の一覧画面から注文の詳細画面を表示できる
  - [ ] 注文の詳細画面にて商品と個数を確認できる
  - [ ] 受け渡しボタンを押すと注文のステータスが受け渡し済になる
  - [ ] ステータスが受け渡し済になった注文は受け渡し前注文の一覧画面にて非表示になる
