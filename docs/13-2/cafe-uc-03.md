#### UC-03: 商品代金を支払う

- **アクター**: お客様
- **事前条件**: 注文する商品が選択されている
- **基本フロー**:
  1. お客様が注文確定ボタンを押す
  2. システムが支払い画面を表示する
  3. お客様が支払いボタンを押す
  4. システムが注文内容を登録する
- **代替フロー**:
  - 4a. 支払いか完了しなかった場合：システムはエラーメッセージを表示し、注文内容を登録しない
- **事後条件**: 注文の確認画面に表示される
- **受け入れ条件**:
  - [ ] 注文確定ボタンを押下すると、支払い画面になる
  - [ ] 支払いが完了すると注文の確認画面に表示される
  - [ ] 支払いが完了しなかった場合、エラーメッセージが表示され注文内容が登録されない
