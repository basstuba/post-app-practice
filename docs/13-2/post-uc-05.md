#### UC-05: 投稿を編集する

- **アクター**: ログイン済ユーザー
- **事前条件**: ユーザーがログインしている。ユーザーと投稿者が同一アカウントである
- **基本フロー**:
  1. ログイン済ユーザーが編集ボタンを押す
  2. システムが編集画面を表示する
  3. ログイン済ユーザーが編集後、更新ボタンを押す
  4. システムが編集内容を保存する
  5. システムが投稿一覧画面を表示する
- **代替フロー**:
  - 1a. ログイン済ユーザーが他のアカウントの投稿の編集画面のURLを直接開いた場合：システムはエラー画面を表示する（403）
  - 3a. 編集時タイトル又は本文が空の場合：システムはエラーメッセージを表示し、編集前の内容を表示する
- **事後条件**: 編集後の投稿が投稿一覧画面に表示される
- **受け入れ条件**:
  - [ ] 編集ボタンを押下すると、投稿の編集画面になる
  - [ ] ログイン済ユーザーと投稿者のアカウントが別のアカウントだった場合、編集ボタンが表示されない
  - [ ] ログイン済ユーザーと投稿者のアカウントが別のアカウントだった場合、編集画面が表示されずにエラー画面が表示される
  - [ ] 更新ボタンを押すと編集内容が保存され、投稿一覧画面に表示される
  - [ ] タイトル又は本文が空の状態で更新ボタンを押すと、エラーメッセージが表示され、編集前の内容が表示される
